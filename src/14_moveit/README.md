# 14_moveit

## Goal
Configure MoveIt 2 for a simulated robot arm.
Plan and execute collision-free motion in RViz2.

## Concepts to learn
- MoveIt 2 concepts (SRDF, kinematics, OMPL planning)
- Planning scenes and collision objects
- Interactive motion planning in RViz2

## Task checklist
- [ ] Set up a minimal MoveIt 2 config for the arm
- [ ] Launch MoveIt 2 with RViz2
- [ ] Plan and execute a joint-space goal
- [ ] Add a collision obstacle and replan around it

## Break it on purpose
- Place a goal pose outside the robot's reachable workspace and inspect the MoveIt planning failure.
