# 09_urdf_rviz

## Goal
Describe a simple robot arm using URDF and Xacro.
Visualize it in RViz2 and move its joints with `joint_state_publisher_gui`.

## Concepts to learn
- URDF links, joints, and geometry
- Xacro macros and properties
- `robot_state_publisher` and `joint_state_publisher_gui`

## Task checklist
- [ ] Write a 2-link arm URDF/Xacro file
- [ ] Create a launch file for `robot_state_publisher` and RViz2
- [ ] Move joints interactively with `joint_state_publisher_gui`
- [ ] Verify TF frames in RViz2

## Break it on purpose
- Create a typo in a joint parent/child link name in the URDF and inspect the XML/URDF parser error.
